implementation. LVO list: NDK 3.2 pragmas, so V44+ (OS 3.5-3.2) functions

the V40 (OS 3.1) API first. Disk libraries (rexxsyslib, amigaguide,
datatypes) are measured through their RAM jump tables; *not loaded*
