# Fred Fish mass run - Phase 237c: the residue

Generated by `python3 -m rdd massrun report` (Phase 232, 237b, 237c).

9943 executables from the Fred Fish disks, each run without input on lxa (v0.11.63) and on AmigaOS 3.1.
The reference results are those of the 237b run (`2026-10-10-fish-massrun.md`, instances 0-7); only the
lxa side was re-run after each fix.  Harness change in 237c: lxa's LIBS: no longer carries the
third-party libraries of `share/lxa/System/Libs` (arp, req, reqtools, powerpacker ...) in mass runs,
because the 3.1 reference does not have them either (Fish ATCopy x2, Helper x2 and ReqTools' demo x3
exit there for want of them).

Gate (roadmap Phase 237c): no lxa-only crash class with 3 or more programs (largest class now 2, was
CHK 4); lxa-only hangs and missing windows halved: **194 -> 68** (hang instead of exit 62 -> 29, exit
instead of window 117 -> 29, hang instead of window 15 -> 10).

Fixed in Phase 237c, each with a probe captured on the reference (`tests/probes`):
