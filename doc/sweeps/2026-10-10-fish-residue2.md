# Fred Fish mass run - Phase 237d: residue II and run time

Generated by `python3 -m rdd massrun report` (Phase 232, 237b-d).

9943 executables from the Fred Fish disks, each run without input on lxa (v0.11.74) and on AmigaOS 3.1
(reference results of 237b, instances 0-7).

Run time (237d): lxaprobe's `WAIT_EXIT 6000` polls 300 times with `Delay(1)`, and a `Delay(1)` takes two
ticks on AmigaOS 3.1 (probe `dos/delayticks`; lxa's Delay() now does the same), so programs run about
12 emulated seconds on the reference (`C:Wait 12` returns within it, `Wait 13` does not).  lxa's budget is
now 600 frames.  Programs whose reference outcome depends on the batch they ran in (libraries an earlier
installer put in LIBS:, a daemon or window an earlier program left, the serial port lxaprobe holds, the
size of the current volume) are listed apart (`ENVIRONMENT_DEPENDENT`), as are programs that read
uninitialised memory (`MEMORY_DEPENDENT`) and programs that finish sooner than the reference
(`FINISHED_SOONER`); every entry was checked.

Gate (roadmap Phase 237d): no lxa-only crash class with 2 or more programs - **met** (largest class 1, was
2); lxa-only hangs and missing windows <= 40 - **not met: 68 -> 52**; the `cluster2-exit` ignore region -
**gone**.

Fixed in Phase 237d, each with a probe captured on the reference (`tests/probes`):

| fix | probe | Fish programs |
|---|---|---|
| Delay() ends at the end of the tick in which it runs out | `dos/delayticks` | (run budget) |
| file operations cost their 3.1 time (RAM: and directory drives) | `dos/iotime` | DiskPerf x2 |
| AllocMem() leaves A1 = result, D1 = 0 after MEMF_CLEAR, flags of the result | `exec/allocregs`, `exec/allocflags` | AskFirst, SofTrack |
| files have a handler port (READ/WRITE/SEEK packets); NIL: has none | `dos/filepkt`, `dos/nilread` | ASendPacket, TurboText TTX |
| CON:/RAW: windows have a handler port (DISK_INFO, SCREEN_MODE, WAIT_CHAR, READ, WRITE) | `dos/conpkt` | Mon |
| Info() sets id_VolumeNode | `dos/infovol` | IInfo |
| asynchronous System() runs its line in a shell | `dos/sysasync` | Recorder |
| potgo.resource | `exec/potgores` | JoyDemo |
| (checked, already right) AllocAbs, GetProgramName, diskfont current directory | `exec/allocabs`, `dos/progname`, `diskfont/curdir` | - |

Harness: blink-safe snapshots (`WAIT_PIXEL ... SNAP` in one lxaprobe command, `WAIT_WINDOW *`), the
Cluster2 golden without ignore region; the `exec/audioirq` "flake" was a beam-position race in the probe
(VPOSR/VHPOSR read as two words across a frame end), fixed in the probe.

## Memory-dependent programs

Their outcome depends on the bytes of the Kickstart ROM or low memory (`MEMORY_DEPENDENT` in massrun.py).

- fish-0099/A-Render/programs/LATHE (lxa crash, 3.1 hang): parses its stdin buffer (AllocMem(1032) without MEMF_CLEAR) although Read() returned 0 at end of file: the answers are whatever the memory held (Phase 237d)
