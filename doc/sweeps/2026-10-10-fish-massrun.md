# Fred Fish mass run - Phase 237b: the full re-run

Generated by `python3 -m rdd massrun report` (Phase 232, 237b).

9943 executables from the Fred Fish disks, each run without input on lxa (v0.11.34) and on AmigaOS 3.1
(the first complete reference run: reference instances 0-7, `LXA_REF_POOL=0-7`), 2026-10-09/10.
Previous runs: `2026-10-03-fish-massrun.md` (lxa only), `2026-10-09-fish-crashlist.md` (the 299-program crash list).

Harness (both sides alike): the program runs from its own directory with stdin NIL:, the Workbench 3.1 fonts,
no assigns to its own S/Libs/C directories (`LXA_PROGDIR_ASSIGNS=0`) and LoadWB's backdrop window
(`LXA_WB_WINDOW=1`).  New in 237b: lxa's 6 s budget starts when the program is loaded (where lxaprobe's
RUN returns) plus 10 frames for the agent's WAIT_EXIT round trip (Fish DumpWB sleeps exactly 6 s); "running"
means the program has not returned, as WAIT_EXIT, so exceptions of tasks it left behind (a shell it started)
do not count once it returned; reference runs retry a program after harness errors.

Fixed in Phase 237b (reference-verified, probes in `tests/probes`): host SIGBUS in WaitForChar on a non-host
handle (Xlisp x4, AmigaFox x3, Hextract x2, J4Neural, novirus); emulator hang in full-screen blit loops
(Marble-Slide: BltBitMap() now costs its 3.1 time, byte-wise host blits); exception vectors in fast RAM via
the VBR as on the 68040 reference (60or80, AHDM x2, Vertex, NewAudio, EatIT ...); misc.resource (VCLI's
voice.library); all registers saved around foreign library init/Open/Close/Expunge and device vectors
(midi.library, voice.library); InitSemaphore keeps D0/D1/A1 (bsh x2); GetCC from user mode (11 CanDo decks);
an ILLEGAL with an unknown call number is the program's illegal instruction, not a silent emulator stop
(Scrambler); SPCmp/IEEExxTst condition codes (Gwin x14).

Triage of the listed items: DW, VChess, ISAM, DumpWB now behave as on 3.1 (Scrambler crashes on both);
ParM SetMouse is memory-dependent (below).  Owners of what is left: the CHK crashes of calendarfactory,
AmigaPunt, Pennywise and the bus errors of SafeBoot/GoWB are Phase 255 (locks, workbench.task); the other
lxa-only crashes and the hangs/missing windows are Phase 239.
